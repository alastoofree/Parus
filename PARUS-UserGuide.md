# PARUS — Краткое руководство пользователя

## Что такое PARUS

PARUS — персональная система управления знаниями. Работает как локальный веб-сервер. Открывается в браузере. Состоит из двух частей:

- **Обычные базы** — для хранения произвольных фреймов знаний
- **Терминологическая база (TERMINUS)** — специализированная база для работы с терминами и понятиями

---

## Запуск

```
go run .
```

Открыть в браузере: `http://localhost:[порт]/portal.html`. В коде стоит порт 3888.

## Обычные базы знаний

### Структура

Каждая база хранится в папке `data/ULID/`. Единица хранения — **фрейм** (`.uic` файл).

### Страница базы (`project.html`)

- Список фреймов
- Поиск по базе
- Кнопки быстрого доступа к тегам с линзами

### Страница фрейма (`frame.html`)

Кнопки в правом верхнем углу:
- `+` — создать новый фрейм
- `⧉` — клонировать фрейм
- `+` (серый) — добавить слот
- `✓` — сохранить

Кнопки линз (переключают панели):
- `✦` — граф связей
- `⬡` — теги
- `≡` — контент
- `◈` — ранг (иерархия, если заполнен слот `rank`)
- `↕` — табы (если заполнен слот `tab`)
- `⊕` — хроно (если заполнен слот `chrono`)
- `⊞` — слоты (редактирование)

Поиск — строка `>` вверху, Enter для поиска по контенту.

### Слоты фрейма

| Слот           | Назначение |
|----------------|------------|
| `title`        | Заголовок фрейма |
| `alias`        | Синонимы (гаусс-индексы) |
| `tags`         | Теги (гаусс-индексы тегов) |
| `links`        | Ссылки на другие фреймы |
| `includes`     | Включения (трансклюзии) |
| `content`      | Основной контент (markdown) |
| `color`        | Цвет фрейма |
| `rank`         | Ранг — делает фрейм тегом, число = глубина иерархии |
| `tab`          | Режим табов (`hrznt` или `vrtcl`) |
| `i-sort`       | Порядок дочерних фреймов |
| `west`         | Слот для западной оси графа |
| `nord`         | Слот для северной оси графа |
| `graph`        | Параметры отображения графа |
| `list`         | Параметры отображения списка графа |
| `chrono`       | Включает хронологическую линзу (`+` или `-` для порядка) |
| `i-chrono`     | Колонки хронологической таблицы |
| `show-product` | Ключи из спутника для отображения продукций |
| `product`      | Вычисляемые продукционные связи |
| `dict`         | Глубина словарных подсказок |
| `i-dict`       | Индексы фреймов-словарей |

### Контент

Поддерживается markdown. Специальный синтаксис:
- `[[индекс]]` — внутренняя ссылка на фрейм
- `{{индекс}}` — трансклюзия (вставка контента другого фрейма)

### Граф

Четыре направления: запад, север, восток, юг. По умолчанию:
- Запад/восток — по слоту `tags`
- Север/юг — по слоту `links`

Параметр `graph`:
- `-west`, `-nord`, `-east`, `-south` — скрыть направление
- `+list` — только список, без SVG
- `-list` — только SVG, без списка

### Хроно

Таблица фреймов с датами. Данные берутся из JSON-спутников фреймов. Ключ `"date"` — дата записи. Слот `i-chrono` задаёт дополнительные колонки.

## TERMINUS — терминологическая база

### Структура

Термы хранятся в папке `KATER/` в виде `.term` файлов. Путь строится из букв имени:
`NORMA` → `KATER/N/O/R/M/A/norma.term`

У каждого терма может быть два спутника:
- `имя.json` — данные (словарь, хроно, процессы, продукции)
- `имя.svg` — иконка

### Страница списка термов (`terms.html`)

- Список всех термов с сортировкой
- Поиск по имени — вводить в строку `>`
- Полнотекстовый поиск — вводить и нажать Enter
- Кнопки быстрого доступа к линзам тегов-термов

### Страница терма (`term.html`)

Кнопки линз:
- `✦` — граф связей
- `⬡` — теги
- `≡` — контент (включая продукции)
- `⊕` — хроно (если заполнен слот `chrono`)
- `⊛` — процессы (если заполнен слот `process`)
- `◈` — ранг
- `↕` — табы
- `⊞` — слоты

Поиск — строка `>` вверху, Enter для поиска по всей базе.

### Слоты терма

| Слот           | Назначение |
|----------------|------------|
| `name`         | Имя терма |
| `alias`        | Синонимы (имена других термов) |
| `uri`          | Путь к папке терма |
| `rank`         | Ранг — делает терм тегом |
| `tags`         | Теги `[ прямые ] [ обратные ]` |
| `links`        | Ссылки `[ прямые ] [ обратные ]` |
| `includes`     | Включения `[ прямые ] [ обратные ]` |
| `color`        | Цвет |
| `content`      | Контент (markdown) |
| `deep`         | Глубина совпадения для продукций |
| `west`         | Слот западной оси графа |
| `nord`         | Слот северной оси графа |
| `graph`        | Параметры графа |
| `list`         | Параметры списка графа |
| `chrono`       | Включает хроно (`+` или `-`) |
| `i-chrono`     | Колонки хроно таблицы |
| `show-product` | Ключи из JSON-спутника для продукций |
| `product`      | Вычисляемые продукционные связи `[ прямые ] [ обратные ]` |
| `process`      | Включает механизм процессов |
| `i-process`    | Термы-процессы для объединения |
| `attribute`    | Атрибуты `[ прямые ] [ обратные ]` |
| `preposition`  | Препозиции `[ прямые ] [ обратные ]` |
| `prefix`       | Префиксы `[ прямые ] [ обратные ]` |
| `suffix`       | Суффиксы `[ прямые ] [ обратные ]` |
| `counts`       | Счётчики (вычисляется автоматически) |
| `q-btns`       | Кнопки быстрого доступа (`rank tab chrono process`) |
| `dict`         | Глубина словарных подсказок |
| `i-dict`       | Пути к термам-словарям |

### Граф терма

Списки в графе обозначаются:
- `TG` / `IT` — теги прямые / обратные
- `LK` / `IL` — линки прямые / обратные
- `IN` / `II` — включения прямые / обратные
- `PD` / `ID` — продукции прямые / обратные
- `AT` / `IA` — атрибуты прямые / обратные
- `PP` / `IP` — препозиции прямые / обратные
- `PX` / `IX` — префиксы прямые / обратные
- `SX` / `IS` — суффиксы прямые / обратные

### Хроно в TERMINUS

Таблица термов с датами из JSON-спутников. Ключ `"date"` обязателен. Слот `i-chrono` задаёт дополнительные колонки. Поддерживает внутренние ссылки `[[имя]]` и внешние `[текст](url)`.

### Процессы в TERMINUS

Таблица операций вида `объект препозиция объект`. Операции хранятся в JSON-спутнике с гаусс-ключами (`oooo`, `oooi`, ...). Слот `i-process` объединяет операции из нескольких термов-процессов.

### Продукции в TERMINUS

Система вычисляет связи между термами через JSON-спутники. Слот `show-product` задаёт ключи для отображения. Слот `deep` задаёт глубину нечёткого поиска термов в значениях ключей. Продукции отображаются под контентом терма.

### Счётчики (`counts`)

Вычисляются автоматически при сохранении. Формат:
`[ LN NA ] [ RT LT ] [ RL NL ] [ RI NI ] [ RD ND ] [ RA LA ] [ RP NP ] [ RX NX ] [ RS LS ] ...`

где: LN=длина имени, NA=алиасы, RT/LT=обратные/прямые теги, и т.д.
